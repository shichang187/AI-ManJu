# 0.7 简单创作流程（本地版）

启动或重新启动 `Novel2ComicDrama/start_workbench.bat`，打开启动器给出的本机地址。
首页只保留三个创作步骤；访谈、原文、手工 JSON、素材绑定和输出设置仍在高级入口。

## 1. 输入故事

直接写人物、事件、对白和结尾。需要时展开「角色、风格与镜头设置」。
已有项目及历史版本在「打开已有项目 · 恢复历史版本」。修改后先保存；重新生成前会保留已有项目，未建项目的旧草稿会先保存为独立项目。

## 2. 模型扩写分镜

「真实模型调用」使用支持 Chat Completions 的接口。展开「模型设置」，填接口地址（通常以 `/v1` 结尾，不含 `/chat/completions`）、服务商实际模型 ID、本机凭据文件完整路径与等待时限。凭据内容由作者在本机文件中管理，页面只填写路径，服务端只从文件读取。配置保存于忽略的私有目录，不写入 Git、项目分镜或对话。

保存设置只检查配置及文件可读性；不会验证服务商账号、余额或模型。点击「扩写并生成分镜」才发送故事、所选指令和创作约束。调用中显示状态；认证、权限、接口不存在、限流、超时、无效 JSON 或截断均显示失败。失败保留旧分镜，不能静默退回本地结果。重复调用会被拒绝；调用期间项目变化会阻止结果覆盖新内容。

从「分镜指令」下拉框选择资料，或在「选择 / 编辑指令」中预览修改。已选指令随草稿/项目保存。已知变量根据当前故事和约束填入；未知变量需先编辑。资料仅在作者选择后用于请求，参考原文不会自动发送。

选择「本地规则分段（离线）」可在未配置模型时起稿，明确标注未调用模型。高级入口保留指令编辑、复制指令与故事、JSON 校验与手动导入。复制请求和直接调用使用同一结构要求；手动结果标注「手动粘贴，来源和模型效果未验证」。不把这两种模式当作实际模型调用成功。

调用状态在私有目录保存；服务重启后未完成调用标为中断。旧环境变量配置继续兼容，新增凭据优先使用本机文件。

## 3. 编辑并生成素材

每镜主要显示画面、提示词和时长；对白、旁白、角色、场景 ID、运镜与字幕放高级入口。可增删、排序、保存。

点击「选择镜头模板」，直接在创作页的弹窗中搜索、预览、填入当前镜头设定、编辑并应用，不需切换资料页。复制镜头提示词到素材平台，按平台实际功能生成并下载视频。工作台尚未接入素材生成 API；豆包免费能力、额度、人物一致性和真实效果未验证。

保存项目，按稳定镜头 ID 命名素材并放入项目视频文件夹，刷新后合成。备选素材或多镜合一在高级入口明确绑定。原有缺镜/路径/媒体预检、版本历史、固定输入快照、项目独立导出和 FFmpeg 失败判定均保留。声音自动对齐、参考图上传、OCR 和媒体关联仍待续。

## 资料用途

- 给对话模型的指令：含模型任务及画面创作约束，用于扩写分镜。
- 直接用于镜头的模板：可编辑画面模板、运镜/风格片段及组合条目；使用前仍需填写与改写。
- 参考原文：长篇完整原文、教程、示例、链接和用途未核实的内容，位于高级入口。

分类由内容规则建议，包含原文/章节/行的 2,270 条私有记录仍不能视为优选模板总数。规则不改原文与出处；个人版本可自行选择用途、保存输入结果与评语。原文、备份、运行输出和模型配置保持私有。

本机检查仅确认现有进程环境未配置完整模型字段，也未发现私有模型配置。实际服务商接口、额度、免费账号能力和创作效果尚未验证。隔离 HTTP 接口与原创故事只用于验证请求、状态和失败保护。
