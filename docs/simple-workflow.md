# 0.8 三步创作流程（本地版）

启动或重新启动 `Novel2ComicDrama/start_workbench.bat`，打开启动器给出的本机地址。首页仍为「输入故事 → 模型扩写分镜 → 编辑并生成素材」。

## 1. 输入故事

写清人物、事件、对白和结尾，需要时展开角色、风格与镜头设置。已有项目和历史版本在高级入口；重新生成前会保存原项目，未建项目的旧草稿先保存成独立项目。

## 2. 配置模型并扩写分镜

默认选择硅基流动，页面提供官网、创建 API Key 和模型广场入口。去官网登录并创建 Key，直接粘贴到工作台的密码输入框，点击「保存并获取模型」，再从实际返回的列表选择对话模型。不必自建凭据文件夹或手写接口地址。

Windows 使用当前用户 DPAPI 加密，密文保存在忽略的 `Novel2ComicDrama/data/private/credentials/`，普通配置只记供应商、接口、模型与凭据方式。保存和关闭后输入框清空，回读只显示已保存状态，不返回 Key、尾号或密文。其他系统只在本次服务会话保存 Key，重启须重填；解密失败会明确提示，不能回退明文。

输入框留空保存会保留同一供应商/接口的 Key；「更换 Key」需要新输入，「清除当前供应商 Key」独立操作。切换供应商或自定义接口不会带走原 Key。自定义兼容接口、手动模型 ID、等待时限、旧凭据文件/环境变量方式放在高级设置。

「保存设置」不发送生成请求。「保存并获取模型」会发送认证后的模型列表请求，但不验证余额、全部模型权限或分镜质量。列表失败保留配置，可再点击重试。可选连接测试仅在主动点击并确认后发送原创短 JSON，可能消耗文本额度。

默认分镜指令为三条经过内容核验的原创指令，分别强调事件完整、对白归属、角色与空间一致。选择后可在高级入口编辑。点击「扩写并生成分镜」才发送故事和所选指令；认证、权限、模型不存在、限流、超时、截断及 JSON 校验失败会显示原因，并保留旧分镜。不会静默换供应商、自动付费重试或退回本地结果。

可显式选择「本地规则分段（离线）」或在高级入口复制请求、粘贴并校验模型结果。这些模式保留明确来源标记。旧环境配置继续兼容，新增默认 Key 通过页面安全保存。

## 3. 编辑并生成素材

每镜可编辑画面、提示词和时长；对白、说话者、角色名单、场景 ID 和字幕放在高级入口。点击「选择镜头模板」，默认显示本机八条已通过内容审核的 Seedance 2.0 单镜适配版。

操作顺序为：选模板 → 填入当前角色与镜头 → 检查预览 → 应用或复制。填入按镜头的角色名单与场景 ID 选择档案，保持说话者归属，时间段随该镜头实际时长计算。支持画幅选择。未知变量必须填写；环境空镜不能直接用在含人物/对白的镜头；过长对白需先按语义拆镜。当前单镜适配范围为3–10秒，这是模板编辑范围，平台实际支持模式和时长另行确认。

应用只替换所选镜头提示词，不修改镜头 ID、顺序、其他镜头或素材绑定；可撤销上次替换。逐项变量、原文、来源入口、审核理由和个人效果记录可展开。所有模板的真实生成效果均标为未实测。

复制提示词到作者当前可用的豆包/即梦 Seedance 2.0 模式，正常生成并下载。硅基流动文本 Key 不代表接通 Seedance 视频 API，也不保证免费额度。工作台仍未自动调用素材生成 API。

保存项目，按稳定镜头 ID 放入素材，刷新后合成。高级多镜合一绑定保留；12–30秒网络多镜示例没有被塞进默认4秒单镜。原有缺镜/媒体/路径预检、版本恢复、项目独立快照、FFmpeg 失败判定保留。实际声音对齐、参考图上传、OCR 和媒体关联仍待续。

## 精选与高级参考库

默认入口只展示八条私有单镜适配版与三条原创分镜指令。旧2,270条私有资料及七条旧入门模板在「高级：全部旧资料与个人版本」，仍可全文搜索、收藏和保存个人版本，不删除原文。旧分类属于规则建议，不等于审核通过。

网络原文、翻译版本、候选、适配版、备份和配置均留在本机私有目录，不进入 Git。采集和去重不自动授予精选资格；截断、锁定、参考素材缺失和模型不明条目保留来源记录。

真实服务商账号权限、额度、分镜质量、Seedance 试片和示例视频观感未验证。本轮仅用虚构 Key、本机假接口和原创故事验证流程。
