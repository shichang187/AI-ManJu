# 工作台 0.6 本地升级

当前首页已按 0.7 恢复三步创作，下文保留 0.6 的可靠性与高级功能说明。最新操作以 [三步创作说明](simple-workflow.md) 为准。

Python 本地服务、原生 HTML/JavaScript 和 FFmpeg 架构保持。旧 CLI、角色与导演模块保留，浏览器合成入口改用严格校验的导出模块。

## 项目与数据

新项目使用 `project_<uuid>` 目录，标题可以重复。`output/browser/<项目 ID>/project.json` 是权威文件，格式版本 2，包含分镜、素材绑定、输入、角色/场景设定及递增版本；`storyboard.json` 是供旧工具使用的兼容副本。修改、提示词应用与撤销都保存到当前项目。历史版本在 `revisions/`，恢复会创建新版本。

旧项目在列表里显示为旧项目。首次明确打开时建立稳定迁移 ID 和新项目记录，素材继续从旧文件夹读取，不改名、覆盖或删除旧项目的任何文件。升级前应备份整个 output 和 data/private。旧的全局成片不会自动移入新项目历史，也不会被删除。

每个导出位于项目的 `exports/compose_<uuid>/`，包含输入媒体副本、分镜快照、素材指纹、临时文件、字幕、规格说明和成片。任务固定保存时的输入版本；同项目按入队顺序处理。刷新可查看任务历史，服务重启后未完成任务显示中断。失败任务保留诊断材料，不能替代旧成片。

## 创作操作

1. 写故事，填角色，完成地点/时间等访谈，生成分镜；本地分段覆盖原故事结尾，支持 1–300 镜。
2. 编辑动作、对白、旁白、运镜、提示词、时长、逐镜角色和场景 ID。增加、删除或排序不改变已有镜头 ID。保存按钮明确反馈失败。
3. 角色/场景档案可编辑 JSON 数组，角色字段兼容 CharacterProfile，参考图通过本地路径记录；服装版本可作为个人附加字段。暂未提供图片上传、缩略图和模型侧自动参考图注入。
4. 提示词资料库在独立页签。搜索、收藏、修改、应用或撤销；完整导演指令可送入创作页的可编辑指令框。复制指令与当前故事、角色和场景，手动粘贴到对话模型。
5. 粘贴模型 JSON，先校验和预览，再导入分镜并编辑保存。当前支持 JSON 对象/数组和 Markdown JSON 围栏；非 JSON 自由文本需手动整理。
6. 创建项目并放入视频，以镜头 ID 命名或手动选择素材。缺镜或重复备选不得自动分摊台词；多镜合一要明确填写连续 shot_ids。
7. 预检真实时长、尺寸、帧率、音轨及视频解码。选择输出规格与留边/居中裁剪，导出后逐版审看。

## 字幕与声音

素材有声时保留其音轨，无声时补静音。旁白与对白可以同时写进字幕。默认只使用用户填写的句级时间，单位是相对对应素材的秒数；多镜合一也以该素材起点为零。勾选计划对白可使用整镜计划文本，但不能声称与实际语音对齐，多镜合一缺少时间时拒绝这种自动分配。自动语音识别、对齐和真实声音一致性尚未验收。

FFmpeg 非零退出、无视频流、无法解码或最终时长/画幅不符均判失败。字幕叠加失败也返回失败，不降级成无字幕成功。经过检查的新文件才从 pending 改名为 final。

## 私有资料库

资料根目录可多个并存，按文件 SHA-256 增量处理。正文原文和编号章节同时保留；表格保留工作表、原行号和列名。来源记录相对路径、文件指纹、包 ID 和章节/表格位置。同内容合并来源。背景任务不锁住旧库搜索，失败或来源丢失时保留既有条目，重试不会误删；可以撤销上次导入。

用途和阶段通过内容规则给出建议，显示尚未人工复核。个人版本保留原文来源，支持重分类、实际输入、结果和人工评语；没有真实生成证据的适配/效果继续未验证。原文、raw、提取、包清单、备份与个人版本只写 `data/private/`，不进入 Git。

独立图片/视频、DOCX 内嵌图片与 PDF 无文本页面明确记录未提取；不据文件名猜案例对应。OCR、媒体内容关联、全库人工优选、最近使用推荐，以及大于当前资料集合的性能仍待实施或验收。

## 启动与验证

双击 `Novel2ComicDrama/start_workbench.bat`。先执行 Python 3.10+ 和 FFmpeg/ffprobe 版本检查；也可通过 `AIMANJU_PYTHON` 指定 Python。Windows App Execution Alias 不能执行时尝试本机已安装的 Codex Python 运行时；没有可执行 Python 时显示安装说明。

服务只监听 127.0.0.1。所有写入和打开文件请求验证 Host、Origin、JSON 类型和本地会话凭证；打开文件限制在工作台输出根目录且仅允许媒体或字幕。凭证仅在进程/页面内存中，不写入项目或日志。

```powershell
python -B scripts/doctor.py
python -B -m unittest discover -s tests -v
```

真实媒体集成测试需要 FFmpeg 和 ffprobe；无依赖时会显示跳过，不能把这种结果当合成通过。远端 CI 配置更新仅本地提交，未执行线上 CI。

模型账号免费能力、额度、最终画面/音频质量与作者审片仍需真实样片验证。隔离测试中的色块和正弦音频是技术测试素材。
